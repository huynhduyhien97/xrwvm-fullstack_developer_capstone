# xrwvm-fullstack_developer_capstone

## Project Name

Cars Dealership - Full Stack Application Development Capstone Project

## Description

A full-stack dealership review application that allows users to browse
car dealerships across the United States, filter dealerships by state,
view dealership reviews, register and log in, and submit reviews.

## Technologies

- Django
- React
- Node.js
- Express
- MongoDB
- SQLite
- Docker
- IBM Cloud Code Engine
- GitHub Actions
